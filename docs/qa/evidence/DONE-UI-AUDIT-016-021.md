## Shared visual and interaction checks from source

- Typography comes from Plus Jakarta Sans in `src/app/layout.tsx`; base foreground/background and brand/focus variables are defined in `src/app/globals.css`.
- Primary action purple (`#8127cf`), ink (`#1f1a23`) and muted text are used across these surfaces. Field and panel radii vary between compact controls and content cards, consistent with their role and the shared UI patterns.
- A global `:focus-visible` selector covers links, buttons, inputs, selects, textareas, summaries and tab stops. Screen-level focus styles add contrast where needed. No keyboard-only hover dependency was identified in the reviewed controls.
- The checked source includes reduced-motion rules globally. These feature screens do not define their own decorative motion; shared summary count/card behavior is covered by PR #36.
- Responsive grids stack at small widths across the locale, model, support and guardian forms. The pupil history uses a vertical ordered list. No current viewport measurements or overflow assertions were made.
- RTL ownership is explicit for locale settings, pupil history and guardian management. Owner support uses `dir="auto"` and isolates identifiers. Academic model direction follows its surrounding role shell, and requires a live ar/ur check.

It did not load `.env`, connect to a remote service/database, use school records, or treat checked-in screenshots as current verification.
