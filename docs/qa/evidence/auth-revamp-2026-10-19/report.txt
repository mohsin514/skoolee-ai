CONFIRMED FINDINGS
CRITICAL / P1 / SKO-499 (related SKO-391, SKO-380, SKO-457): Deferring MFA signs a new SUPER_ADMIN out after successful onboarding activation. Reproduced twice in joined signup runs and independently from a seeded review step. Before activation: mfaVerified="deferred", session HTTP 200. After: mfaVerified=false, session HTTP 401, login redirect. OnboardingComplete stays true and campus creation succeeds. Root cause: src/lib/auth.ts:18,56 coerces state to boolean and completeOnboarding.ts:118 reissues only payload.mfaVerified===true. Expected: preserve the authorized deferred state while maintaining enrolled-factor guards. This is a confirmed integration regression requiring a fix before treating the new-owner flow as passed.
F1 / P2 / SKO-391: Failed campus deletion closes confirmation before server acknowledgement. A failed POST leaves the campus present, shows "Your setup could not be loaded..." and retains "Saved to your account". Reproduce with a group campus, trash icon, block onboarding POST, confirm. Expected: deletion-specific failure and retry in retained dialog; accurate saved/pending state. Source: use-setup-wizard.ts confirmDeleteCampus, generic persist catch. No data loss observed.
F2 / P2 / SKO-391: Website accepts and durably saves "not a valid website". Enter in group identity, Continue, Back; database draft and charter preview contain malformed value. Expected validated/normalized supported URLs, linked inline error and retained input. Source: setup-state.ts identity validation lacks website rule.
F3 / P2 / SKO-457: Verification/reset templates have English-only copy and no language prop; email sending helpers pass no recipient locale. Expected AR/UR localized subject/body/CTA/expiry and matching lang/dir. Source/render finding, not an observed delivered email.
F4 / P3 / SKO-457: At 320px verification-email CTA arrow wraps below its label. No horizontal overflow; cosmetic issue.
These findings are current-baseline defects/polish gaps. Their introduction by a particular revamp commit was not independently established.
