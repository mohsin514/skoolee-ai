## Product changes
- `src/lib/ai/pseudonymize.ts` — the outbound scanner now folds Arabic-Indic (٠-٩) and Extended
  Arabic-Indic/Urdu (۰-۹) digits before matching (NFKC does not), and adds Gulf grouped local mobiles
  (`050 123 4567`), Emirates ID (`784-YYYY-NNNNNNN-N`) and IBANs. Previously a guardian number written in
  Arabic digits passed the egress check.
- `src/lib/ai/evaluation.ts` — `assessAIPromotion()`: promotion requires a recorded evaluation of the exact
  model + prompt version + policy version + dataset version, a named reviewer and time, a passing result for
  every case, educator review for Arabic/Urdu-quality and answer-key cases, and re-checks every privacy case
  against the live scanner (a scanner regression blocks promotion).
- `src/config/ai-release-evaluation.ts` — the release evaluation record; intentionally `null` until real
  educator results exist. `scripts/check-ai-release.ts` / `npm run check:ai-release` is the release gate.
